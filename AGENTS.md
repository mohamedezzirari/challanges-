# Project Guidance

## Scope

- This is a small, standalone JavaScript practice workspace.
- The current exercises are top-level files: `challanges.js` and `challange2.js`.
- Keep changes local to the exercise being discussed; do not introduce frameworks, package metadata, or shared abstractions unless requested.

## Running Code

- Run an exercise directly with Node.js, for example: `node challange2.js`.
- There is currently no package manager, build script, or test suite. Do not assume `npm test` or a project build command exists.
- Use a focused Node.js execution as the cheapest behavior check after changing an exercise.

## Style

- Preserve the existing beginner-friendly, top-level script style and simple `console.log` output.
- Match the existing naming and language in the exercise unless the user asks for a correction or refactor.
- Avoid unrelated formatting changes and keep examples easy to read.

## Quick Suggestions

- For a request for a quick suggestion, inspect the relevant exercise first and give one or two concrete next steps.
- Prefer small practice improvements, such as extracting repeated output, validating an input, or adding one edge-case example.
- Explain the suggestion briefly before editing; make code changes only when the user explicitly asks for implementation.
